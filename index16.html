Sentiment Analysis & LLM Fine Tuning

Python + LLM + LORA (2025)

Our organization, with staff force over 4,000, has a wealth of valuable feedback captured in training evaluation reports dating back to 2013. We aim to develop a AI-empowered solution to extract and analyze this information, transforming unstructured text into strategic insights.

Smarter Approach

Using a large language model (LLM), we've successfully performed sentiment analysis on thousands of evaluation reports. Benefit from the Natural Language Processing (NLP) power of LLM, which can accurately analyze user feedback in multiple languages, including English and Chinese. The analyzed result is applied to fine-tune (MLX framework) the LLM using LoRA (Low-Rank Adaptation).

(Unified memory utilization: ~40GB)

LinkYouIn: AI Recruiter

Local-First Intelligent Recruitment Assistant using Dual LLMs

Python + FastAPI + Ollama (2025)

The Challenge

Recruiters often spend less than 10 seconds scanning a CV. High-volume hiring leads to fatigue and bias. Commercial AI tools often pose data privacy risks by sending sensitive PII to third-party clouds.

The Solution

LinkYouIn is a privacy-centric pipeline designed to run on local hardware. It processes CVs (PDF/DOCX) through a multi-stage AI analysis pipeline using Ollama. It orchestrates two distinct LLMs (Qwen & Gemma) to score candidates in parallel.

Dual-Model Consensus

Orchestrates two quantized LLMs. Scores are averaged to create a balanced "Job Fit" metric.

Holistic Analysis

Analyzes "Career Stability" and "Interest Levels" using a separate analyst agent.

Privacy First

Runs entirely locally. No candidate data is ever sent to external APIs.

Fault Tolerance

Designed to fail gracefully; defaults to secondary model if one hangs.

Core Pipeline Logic

pipeline.py
def score_cv(cv_path, job_req, salary):
    cv_text = extract_text(cv_path)
    
    # 1. Parallel Job Fit Scoring (Qwen + Gemma)
    with ThreadPoolExecutor(max_workers=2) as exc:
        job_fit_func = partial(ask_llm_fit, job_req, cv_text)
        results = list(exc.map(job_fit_func, [LLM_MODEL_1, LLM_MODEL_2]))
    
    # 2. Serial Deep Analysis
    interest_score = ask_llm_interest(cv_text, job_req, salary)
    
    return {
        "job_fit_score": (results[0] + results[1]) / 2,
        "interest_score": interest_score
    }
