LINK_YOU_IN

NEW

Local-First Intelligent Recruitment Assistant.

Recruiters spend <10s scanning CVs. LinkYouIn runs entirely locally to process PDF/DOCX CVs through a multi-stage AI analysis. It orchestrates two distinct LLMs (Qwen & Gemma) via Ollama to reduce hallucination.

  • Dual-Model ConsensusAverages scores from two LLMs.
  • Privacy FirstNo data sent to cloud APIs.
  • Holistic AnalysisChecks career stability & interest.
  • Fault ToleranceFail-safe pipeline design.
pipeline_logic.py 
def score_cv(cv_path, job_req, salary):
    cv_text = extract_text(cv_path)
    
    # Parallel Job Fit Scoring (Qwen + Gemma)
    with ThreadPoolExecutor(max_workers=2) as exc:
        job_fit_func = partial(ask_llm_fit, job_req, cv_text)
        results = list(exc.map(job_fit_func, [LLM_MODEL_1, LLM_MODEL_2]))
    
    return {
        "job_fit_score": (results[0] + results[1]) / 2,
    }
